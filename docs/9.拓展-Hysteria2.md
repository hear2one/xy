# XHTTP + CDN 搭建指南 (九)：拓展 - Hysteria2

Hysteria2 使用已有 SSL/TLS 证书，可选择独立 UDP 端口或端口跳跃范围；普通 HTTP/3 请求反向代理到 Nginx 回落页面。

## 1. 端口与文件

Hysteria2 默认使用单个 UDP 8443，也可启用端口跳跃并输入范围（默认 `20000-50000`）和跳跃间隔（默认 30 秒、最少 5 秒）。范围不能包含 XHTTP H3 使用的 UDP 端口。

端口跳跃使用 Hysteria2 2.8.0+ 的 Linux 内置范围监听。服务端自动通过 nftables 或 iptables 把范围内其他端口重定向到首个端口，并在服务停止时清理规则。VPS 系统防火墙和云平台安全组仍需放行整个 UDP 范围。

服务端文件：

```text
/usr/local/bin/hysteria
/etc/hysteria/config.yaml
/etc/ssl/private/fullchain.cer
/etc/ssl/private/private.key
```

单端口模式放行：

```text
UDP 8443
```

端口跳跃模式例如放行：

```text
UDP 20000-50000
```

## 2. 安装

### systemd 发行版

```bash
HYSTERIA_USER=root bash <(curl -fsSL https://get.hy2.sh/)
```

### Alpine Linux

`x86_64`：

```sh
curl -fL https://github.com/apernet/hysteria/releases/latest/download/hysteria-linux-amd64 -o /usr/local/bin/hysteria
chmod +x /usr/local/bin/hysteria
```

`aarch64`：

```sh
curl -fL https://github.com/apernet/hysteria/releases/latest/download/hysteria-linux-arm64 -o /usr/local/bin/hysteria
chmod +x /usr/local/bin/hysteria
```

## 3. 配置

创建目录并编辑配置文件：

```bash
mkdir -p /etc/hysteria
vi /etc/hysteria/config.yaml
```

```yaml
# 单端口
listen: :8443

# 或端口跳跃（Hysteria2 2.8.0+）
# listen: :20000-50000

tls:
  cert: /etc/ssl/private/fullchain.cer
  key: /etc/ssl/private/private.key

auth:
  type: password
  password: YOUR_HY2_PASSWORD

masquerade:
  type: proxy
  proxy:
    url: https://127.0.0.1:8003
    rewriteHost: false
    insecure: true
```

Hysteria2 客户端的 SNI 使用已有 Reality 域名。Nginx 的 Reality 域名 `server` 块决定回落页面。

## 4. 服务

### systemd 发行版

服务文件：

```text
/etc/systemd/system/hysteria-server.service
```

```ini
[Unit]
Description=Hysteria2 Server
After=network.target

[Service]
ExecStart=/usr/local/bin/hysteria server --config /etc/hysteria/config.yaml
Restart=on-failure
RestartSec=5
LimitNOFILE=1048576

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable --now hysteria-server
```

### Alpine Linux

服务文件：

```text
/etc/init.d/hysteria-server
```

```sh
#!/sbin/openrc-run

name="hysteria-server"
description="Hysteria2 Server"
command="/usr/local/bin/hysteria"
command_args="server --config /etc/hysteria/config.yaml"
command_background=true
pidfile="/run/hysteria-server.pid"
output_log="/var/log/hysteria-server.log"
error_log="/var/log/hysteria-server.log"

depend() {
    need net
}
```

```sh
chmod +x /etc/init.d/hysteria-server
rc-update add hysteria-server default
rc-service hysteria-server start
```

## 5. 证书续期

systemd 发行版：

```bash
acme.sh --install-cert -d reality.example.com --ecc \
  --key-file /etc/ssl/private/private.key \
  --fullchain-file /etc/ssl/private/fullchain.cer \
  --reloadcmd "systemctl restart hysteria-server; systemctl restart nginx"
```

Alpine Linux：

```sh
acme.sh --install-cert -d reality.example.com --ecc \
  --key-file /etc/ssl/private/private.key \
  --fullchain-file /etc/ssl/private/fullchain.cer \
  --reloadcmd "rc-service hysteria-server restart; rc-service nginx restart"
```

## 6. Mihomo

文件：

```text
/home/USERNAME/client-config-mihomo-full.yaml
/home/USERNAME/client-config-mihomo-nodes.yaml
```

```yaml
  - name: hysteria2 直连
    type: hysteria2
    server: VPS_IP
    port: 8443
    # 启用端口跳跃时增加：
    # ports: "20000-50000"
    # hop-interval: 30
    password: "YOUR_HY2_PASSWORD"
    sni: reality.example.com
    alpn:
      - h3
```
